# Osmium

A content-first WordPress block theme for writers, publishers, and review sites. Full Site Editing, theme.json v3, patterns over CSS, no theme JavaScript.

Status: planning (2026-09-09). No theme files exist yet.

Osmium is element 76, the densest natural element and the metal that tipped fountain pen nibs for most of the last century. Small package, a lot packed in, named after the tip of the pen.
